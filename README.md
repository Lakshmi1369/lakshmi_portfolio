## Running locally

No installation needed. Either:

- Double-click `index.html` to open it directly in a browser, or
- Serve it locally for a closer-to-production feel:
  ```bash
  python3 -m http.server 8000
  ```
  then visit `http://localhost:8000`

## Deployment

This is a static site, so it works on any static host:

- **GitHub Pages** — Settings → Pages → deploy from the branch containing `index.html`
- **Vercel** — import the repo; Framework Preset "Other", no build command, Output Directory blank
- **Netlify** — drag and drop the folder at [app.netlify.com/drop](https://app.netlify.com/drop)
